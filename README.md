# .github

This repository holds the public organization profile and the default community health files for [QRCodeKIT](https://github.com/qrcodekit).

QRCodeKIT is a SaaS platform and API for creating, managing and tracking dynamic QR codes, including GS1 Digital Link QR codes for products and packaging. Not the Swift package of the same name.

- `profile/README.md`: the page shown at [github.com/qrcodekit](https://github.com/qrcodekit)
